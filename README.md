# Atlas

Discover the internet beyond search.

Atlas is a curated discovery platform that helps you explore websites you wouldn't normally find through traditional search engines. Instead of endless search results, Atlas organizes the web into carefully curated signals, collections, and recommendations.

Whether you're looking for creative portfolios, interactive experiments, browser toys, digital art, open-source projects, or hidden gems, Atlas is designed to make discovering the internet an experience.

## Features

- Curated website archive
- Featured Signals
- Discovery Console with search and filters
- Signal Detail pages
- Rabbit Hole recommendations
- Curated collections
- Responsive, terminal-inspired interface
